# Data sources

This document summarizes the data sources described in the manuscript.

## Influenza incidence data

The manuscript uses daily influenza-related medical-use counts from the National Health Insurance Service (NHIS) of Korea.

Influenza-related diagnosis codes:

```text
J09
J10
J11
```

Data source described in the manuscript:

```text
https://www.data.go.kr/data/15089429/fileData.do
```

## Subway mobility data

The manuscript uses subway passenger-volume data by station, date, and time slot. The mobility factor is constructed using boarding counts only.

The manuscript describes public subway data sources including:

```text
https://www.data.go.kr/data/15048032/fileData.do
```

For periods not fully covered by public datasets, the manuscript states that additional subway data were obtained directly from the relevant authorities upon request.

## Population data

Population denominators were derived from resident registration population statistics released by the Ministry of the Interior and Safety.

Population data source described in the manuscript:

```text
https://jumin.mois.go.kr
```

## Analysis periods

```text
2016~2017: 2016-09-01 to 2017-08-31
2017~2018: 2017-09-01 to 2018-08-31
2018~2019: 2018-09-01 to 2019-08-31
2022~2023: 2022-09-01 to 2023-08-31
```
